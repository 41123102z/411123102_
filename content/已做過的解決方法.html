已做過的解決方法

一、 針對 OpenCV (cv2) 安裝的嘗試

這是為了解決 import cv2 失敗的問題，你嘗試了多種繞過網路限制的方法：

  • 標準指令安裝： 嘗試在 Anaconda (base) 環境下執行 pip install opencv-python，但被 Proxy 攔截。

  • 手動觸發認證視窗：

    • 嘗試透過指令引發 Windows 安全性驗證 視窗來輸入帳號密碼。

    • 使用 PowerShell 指令 (Get-Credential) 試圖強行叫出登入框。

  • 清除網路快取與環境變數：

    • 使用 set http_proxy= 等指令清空視窗內的代理設定。

    • 使用 pip config list --debug 追蹤隱藏在 Y:\miniconda3\pip.ini 等路徑下的設定檔。

    • 嘗試執行 pip config unset 想要挖掉寫死的 Proxy 位址。

  • 隔離環境安裝： 使用 pip --isolated 試圖無視所有設定檔進行安裝。

  • 切換物理網路： 為了避開學校 Proxy，你切換到了 手機熱點，並嘗試在無 Proxy 環境下安裝。

二、 針對系統環境的檢查

  • 查詢系統代理： 使用 netsh winhttp show proxy 確認系統層級是否開啟代理。

  • 解析 PAC 腳本： 發現並讀取了 http://127.0.0.1:50552/proxy.pac，確認了電腦後台有軟體在劫持網路流量。

  • 檢查認證管理員： 確認 Windows 是否有存入錯誤的舊密碼導致無法彈出輸入框。

仍無法解決。
